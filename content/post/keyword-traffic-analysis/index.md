## 什么是关键词流量分析？

关键词流量分析是指检查特定关键词如果排名靠前，能为您的网站带来多少流量的过程。此分析可以帮助您确定哪些关键词需要优先考虑。

例如，当有人在 Google 上搜索“电子邮件营销工具”时，就会出现结果页面。如果用户点击了您的网站搜索结果，那么此次访问就是关键字流量（也称为关键字搜索流量）。


## 为什么关键词流量对SEO成功至关重要

关键词流量分析可以识别哪些关键词已经为您的网站带来了流量，哪些关键词可以带来更多流量。利用这些数据，您可以创建或优化内容，以定位这些高潜力关键词。

更好地瞄准领导者，以获得更高的排名、更多的网站访问者，并最终获得更多的潜在客户和销售额。

这是一个例子。

Shopify 在关键词“如何建立电子邮件列表”中排名第一。


但他们的文章位于关键词“如何增加电子邮件订阅者”搜索结果的第八页，其意图（搜索背后的目的）与第一个关键词相似。


关键词流量分析凸显了这一差距。

Shopify 可以决定是否优化现有文章以针对其他关键词，或者创建专注于增加电子邮件订阅者数量的新内容。

## 如何进行关键词流量分析

### 检查预估关键词流量

预估关键词流量显示的是如果您对某个关键词进行排名，可能会收到的大致访问次数。

使用此指标优先考虑具有高相关流量潜力的关键词。最终吸引合适的目标受众访问您的网站，最大限度地减少内容预算浪费，并最大限度地提高收入潜力。

在关键字概览工具中，输入搜索词和您的域名以获得个性化流量潜力。

仪表板将显示重要的关键字指标，例如：

- **搜索量**：平均每月搜索次数
- **个人关键词难度：**_你的_网站对该关键词进行排名的难度

现在，查看“潜在流量”和“潜在主题流量”部分

潜在流量显示如果您针对该关键字进行排名，您的网站每月可能获得的流量估计量。

潜在主题流量向您展示了通过使用所分析关键字的高容量变体可以获得的流量估算。

向下滚动到“SERP 分析”部分以获取更多数据并选择“ **URL** ”概览。

在“搜索流量”栏中，查看每个排名靠前的页面每月获得的流量。

这些估算值可以帮助您根据排名位置计算出您将获得的流量，或者根据排名提升预测您将获得的流量。


  

### 在 Google Search Console 中检查关键字流量

Google Search Console (GSC) 会显示您的网站从特定关键词获得的流量。这些数据揭示了哪些词组带来了最多的访客、哪些方面可以提升流量，以及根据当前效果需要优化哪些关键词。

方法如下。

登录您的 GSC 帐户并选择您想要分析的站点。

点击“**性能”下的“搜索结果**” 。


该性能图显示了四个关键指标：

- **总点击次数**：搜索结果的访问次数
- **总展示次数**：您的网站在搜索结果中出现的次数
- **点击率 (CTR)**：促成点击的展示次数百分比
- **平均排名**：您的网站在所有搜索查询中的平均排名

向下滚动即可查看效果最佳的关键字，在 GSC 中称为“查询”。

此列表按点击次数排序，显示哪些查询为您的网站带来了最多的访问者。


这些是您表现最佳的查询。记录这些查询并跟踪流量随时间的变化，以便您能够快速应对流量骤降。本文稍后将向您展示如何使用位置跟踪轻松实现这一点。

为了找到改进的机会，请单击“**点击率**”两次，将列表按点击率从最低到最高排序。


这些术语指的是您的网页经常出现但点击次数不多的情况。

检查“**位置**”选项卡以查看平均位置并确认此页面排名较低。


通过针对这些术语优化页面，您可以提高排名并吸引更多访问者。

### 连接 Google Search Console 和 Google Analytics 以获取更多见解

将 GSC 与 Google Analytics（GA4）连接起来，可以让您更深入地了解为什么点击率低的查询和页面表现不佳。

要链接 GSC 和 GA4，请打开左侧菜单并单击“**管理**”。


在“产品链接”下，点击“ **Search Console 链接**”。


点击“**链接**”连接GA4和GSC。


在“选择 Search Console 资源”部分中，点击“**选择帐户**”。


选择您要连接的网站。然后点击“**确认**”。


接下来，为您的域选择一个网络流，然后单击“**下一步**”。


最后，检查数据并点击“**提交**”。


您的 GSC 和 GA4 数据现已关联。让我们看看您可以利用这些洞察做什么。

在左侧菜单中，点击“**报告**”>“**搜索控制台**”>“ **Google 自然搜索流量**”。

在此视图中，您可以看到来自两个工具的组合数据。

假设您在 GSC 中发现一个页面，该页面在搜索结果中排名较低，但仍获得一些点击。

现在，您可以使用 GA4 检查“每个活跃用户的平均参与时间”等指标。此指标显示用户在您的页面上花费的平均时间。


互动时间短意味着用户浏览完您的页面后很快就会离开。这可能是由多种原因造成的，例如页面加载速度不够快，或者内容无法解答他们的疑问。

利用这些数据来识别表现不佳的页面，分析问题并进行改进。改进这些页面可以增加获取更多关键词流量的机会。

### 分析关键词差距以获得内容优化思路

关键词差距分析会将您的内容与竞争对手的内容进行比较，以找出竞争对手在哪些方面吸引了您无法吸引的流量。这样，您就可以找到内容优化的思路。

方法如下。

打开关键词差距。

输入您的页面 URL 和竞争对手的 URL。

为两个页面选择“**精确 URL** ”，以便您可以分析两者之间的差异。

点击“**比较**”。


下一页的图表显示了您和您的竞争对手有多少个共同的关键词。


向下滚动到“ 的**所有关键字详情**”，然后选择“缺失”。


这些是您的竞争对手排名但您没有排名的关键词。


现在，点击“**弱**”来查看你们两个都有排名的关键词，但你的排名低于竞争对手。


当您确定值得定位的关键字后，点击它进入[关键字概览](https://www.semrush.com/analytics/keywordoverview/)，查看该关键字的预计流量。


通过更新你的文章，使其定位到其中一些关键词变体，你可以增加该特定页面的流量，并提升该内容资产的生命周期价值。确保它持续带来相关的流量和收入，并超越创建它所需的投资。

### 分析竞争对手的关键词流量以寻找新思路

竞争对手的关键字流量分析显示了竞争对手的访客来源，从而揭示了您也可以定位的高流量关键字。

使用这些见解来创建新内容或更新现有页面以捕获部分流量。

以下是如何使用Organic Research进行竞争对手流量分析。

输入竞争对手的网址。然后点击“**搜索**”。


点击“**排名**”。您将获得该竞争对手排名的关键词列表。

“流量”列将显示您的竞争对手从特定关键字获得的流量估算值。


分析此列表以找到您也可以定位的关键字，并获得流量估算，即如果您的网站能够超越竞争对手，可以获得多少流量。

选择您想要定位的关键字，然后单击“ **+添加到关键字列表**”以将其保存在关键字策略生成器中。


为您的列表命名。然后点击绿色复选标记进行保存。


在关键字策略生成器中找到这些关键词，开始制定内容计划，根据竞争对手的研究来增加关键字流量。

  

## 权衡各种因素以确定关键词的优先级

确定关键词的优先级需要权衡多种因素。结构化的评分系统可以帮助您选择对流量和业务目标影响最大的词组。

为了帮助您，我们创建了一个包含所有加权因素的示例评分框架。

在这个例子中，我们将列出所有因素并赋予它们 1、2 或 3 的分数。最后，将分数相加以找到潜力最大的关键词。

|   |   |   |   |
|---|---|---|---|
|因素|1 = 低优先级|2 = 中等优先级|3 = 高优先级|
|交通潜力|流量潜力低（每月访问量少于 50 次）|中等流量潜力（每月访问量 50 至 500 次）|高流量潜力（每月超过 500 次访问）|
|个人关键词难度|竞争激烈（PKD % 超过 70%）|具有一定竞争力（PKD % 在 40% 至 70% 之间）|竞争程度低（PKD % 低于 40%）|
|内容相关性|与受众的需求、内容目标或产品不太相关|与部分受众需求或内容目标相关，但与核心内容无关|与您的受众需求、内容目标和/或您的产品直接相关|
|现有业绩|排名已经很好，并且带来流量|排名和流量下降；有一定的知名度，但仍有改进空间|点击率非常低，如果改进的话，有很大的潜力可以带来流量|
|竞争格局|未发现明显的内容差距|发现了一些内容差距，但与您的产品无关|明确与您的产品相关的内容差距机会|

使用此评分系统作为评估和确定关键词优先级的起点。随着您不断完善目标并进一步了解受众群体和竞争情况，请进行调整。

## 跟踪关键词排名以确定关键词流量

关键词研究的最后一步是跟踪关键词位置，以了解排名如何影响关键词流量，并帮助您检测高流量术语突然下降等问题。

使用位置跟踪来自动化此过程并轻松保持搜索结果中的排名靠前。

初始设置后，该工具会为您跟踪排名并自动向您发送更新。

要设置位置跟踪，请单击“ **+创建项目**”。


输入域名和项目名称。然后点击“**创建项目**”。


选择您想要跟踪位置的搜索引擎、设备和位置。

点击“**继续关键词**”。


您可以手动输入关键字，也可以从关键字策略生成器或 Google Search Console 等工具导入关键字。


点击“**关键词策略生成器**”。然后选择之前进行竞争对手研究时保存的列表。

点击“**导入关键词**”>“**将关键词添加到广告系列**”。


默认情况下，该工具会每周向您发送排名更新。如果您不想收到此信息，请取消选中此框。

然后，点击“**开始跟踪**”。


该工具完成分析后，您将看到域名的摘要，以及可见性、估计流量和平均排名。

单击“**概览**”选项卡可查看估算流量和其他关键字指标。


向下滚动到“排名概览”部分。

这些是您之前输入的关键字，以及页面排名、估计的关键字流量、搜索量等。


了解哪些关键词能为您的网站带来最多的流量，有助于您在搜索结果中保持较高的可见度，并确保您的自然流量保持强劲。
